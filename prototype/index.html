Quick start

  1. Click Share game window and pick the MapleStory window. Picking the window rather than the whole screen keeps the regions accurate if the window moves.
  2. Click Grab frame below. Check that each coloured box covers its text. To fix one, select it in the list and drag a new box on the image.
  3. Click Test OCR. Each region should read correctly. If the black-on-white preview is messy, adjust that region's threshold slider.
  4. Go to Live, check name/class/level, then click ▶ Start session. Use ⧉ Pop-out overlay for a small always-on-top window over the game. Run the game windowed or borderless, not exclusive fullscreen.

Performance & detection

The capture runs at about 4 fps. Only the small regions are OCR'd, and a region is skipped when its pixels haven't changed since the last read. Raise the tick values to save even more CPU.
